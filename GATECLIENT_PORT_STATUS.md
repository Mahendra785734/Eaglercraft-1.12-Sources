# GateClient 1.6 Eaglercraft port

This branch contains the Eaglercraft-native port foundation. The main branch is unchanged.

Build output is produced by the `GateClient Eaglercraft build` GitHub Actions workflow after the TeaVM compile and offline HTML packaging steps succeed.

Current implementation stage: module lifecycle, keyboard binding hook, Right Shift ClickGUI, and initial HUD/movement modules. Remaining original GateClient modules are not yet ported.
